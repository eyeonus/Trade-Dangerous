# Archive

This folder contains **legacy and dormant modules** from the Trade Dangerous
codebase. They are **not used in current workflows** and are **not maintained**,
but are retained for reference and historical context.

## Purpose

- Preserve code that was once part of Trade Dangerous, but is now obsolete or
  superseded.
- Document features that illustrate the project’s evolution (e.g. pre-API OCR
  workflows, deprecated export formats).
- Provide a starting point if anyone wishes to revisit or revive old ideas.

## Current Contents

- **update_gui.py**  
  Text-based GUI for manual entry of station prices, dating back to the
  *OCR era* (before FDev API or EDDN). Used to generate `.prices` files for
  upload to Maddavo’s site. Purely historical.

- **jsonprices.py**  
  Deprecated JSON exporter, retained for backward reference. Emits a warning
  when run.

- **mapping.py / edapi_plug.py**  
  Experimental modules for direct API ingestion. Left here as a reference point
  but non-functional against the current FDev API.

- **journal_plug.py / netlog_plug.py**  
  Early attempts at importing player logs. Never widely adopted; superseded by
  community tools.

- **tradedangerous/gui.py**  
  eyeonus' legacy dynamic Tk based GUI. Builds a front-end around the TD CLI
  and dynamically exposes commands, arguments and plugin-driven options.
  Historical only.

- **ide/TradeDangerous.pyproj / ide/TradeDangerous.sln**  
  Old Visual Studio / Python Tools for Visual Studio project files from an
  earlier Windows development workflow. Retained as historical project
  metadata, not part of the current toolchain.

- **tools/fix-indent.sh**  
  Small maintenance helper for normalizing indentation around blank lines in
  Python files. Retained as a historical repo utility.

## Archived Scripts

The `scripts/` folder has been fully archived.  

These files provided shell/batch wrappers, bash completion, and helper tools
for early adopters. They are not used by current workflows and are not
maintained. Notable examples:

- `tdrun`, `tdloc`, `tdnav`, `tdupd`, `tdbuyfrom` — bash wrappers around CLI commands.
- `trade.bat`, `tradebrute.bat`, `WINDOWS.txt` — Windows batch helpers, tied to `.prices` or early bootstrap.
- `td-completion.bash` — bash completion (included legacy plugin options).
- `config.sh`, `getstation.sh` — env preload and logfile parser; not referenced.
- `README.txt` — bootstrap instructions.

If needed in future, they can be restored from `archive/scripts/`.

# Archived Docs Notes

This directory tracks documentation content that referenced modules now
archived or deprecated.

## Sphinx stubs

The auto-generated API docs under `docs/source/` were created by
`sphinx-apidoc`. They still contain `.. automodule::` references to
modules we have archived:

- `tradedangerous.plugins.edapi_plug`
- `tradedangerous.plugins.journal_plug`
- `tradedangerous.plugins.netlog_plug`
- `tradedangerous.plugins.maddavo_plug`
- `tradedangerous.jsonprices`

These references will cause warnings or errors during a Sphinx build
unless they are pruned. The stubs should either be:
- regenerated with `sphinx-apidoc` after archiving those modules, or
- edited to remove the `automodule` entries for archived code.

## Archived Sphinx Files

- **docs/sphinx/index.md**  
  Old Sphinx landing page for the archived documentation snapshot.

- **docs/sphinx/conf.py**  
  Historical Sphinx configuration for that snapshot, including old path and
  extension assumptions.

- **docs/sphinx/Makefile / docs/sphinx/make.bat**  
  Standard Sphinx build wrappers kept with the archived docs tree.

- **docs/sphinx/source/modules.md**  
  Top-level API toctree stub generated by `sphinx-apidoc`.

- **docs/sphinx/source/tradedangerous.md**  
  Auto-generated API stub for the main package. Includes references to modules
  that have since been archived or disappeared.

- **docs/sphinx/source/tradedangerous.plugins.md**  
  Auto-generated API stub for plugin modules. Includes legacy plugin references
  that no longer line up cleanly with the live tree, which is acceptable for
  the archive.

## Policy

- **Do not delete** the whole `docs/source/` tree, since it is still
  valuable for live modules.
- **Remove or comment out** only the stale `automodule` blocks listed
  above.
- Update `develop.md` with the correct `sphinx-apidoc` invocation when
  regenerating docs so the archive state is respected.



## Policy

- **Do not refactor**: These files are frozen in their legacy form.
- **Do not import**: No active commands or plugins depend on them.
- **Safe to delete**: If space or clarity is critical, this directory can be
  removed without affecting supported features.
