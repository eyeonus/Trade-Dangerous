# Trade Dangerous Session Handoff Template

Use this at the end of any task that risks overrunning one session.

## Task purpose
- What checkpoint and subtask was being worked on?
- What was the exact intended outcome?

## Files touched
- List every file changed or inspected in a way that matters.

## What changed
- Describe the substantive changes already completed.
- Keep this factual.

## Tests run
- List commands run.
- Record pass/fail honestly.
- If no tests were run, say so.

## Outstanding failures / unknowns
- What is still broken?
- What remains unverified?
- What assumptions are still hypotheses?

## Next exact action
- One concrete next step only.
- Make it the thing the next worker session should do first.

## Acceptance criteria for resume
- State the exact condition that would make this subtask complete.

## Rollback point
- State the last known good commit or stopping point.

## Notes for the next session
- Mention any repo-state traps, half-finished edits, or local reasoning boundaries.
